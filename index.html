JavaScriptDjangoHTMLTailwind CSS

Yohan Ihawan Database

PostgreSQL
The problem
Yohan Ihawan, a grilled-food store, had trouble keeping track of its items. Without one reliable record, it was hard to know what was in stock and what had been sold.
Architecture and tech stack
A database-only project built in PostgreSQL. Store items are kept in organized, related tables so every record lives in one place and is easy to look up and update.
My contributions
  • Did everything on this project, from planning to building it.
  • Designed the database structure and set up the tables for the store’s items.
Results and testing
A working database that solves the store’s item-tracking problem. Built as my final project for IT 6.
